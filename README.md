# gsagysinventory
**Inventory Management System for a Local Club**

The **Inventory Management System for a Local Club** is a web-based application designed to manage and track the inventory of multiple items provided to club members. The system maintains essential information such as item details, order details, and the status of each ordered item, enabling efficient inventory management and record keeping.

The application is developed using the **MERN Stack** (MongoDB, Express.js, React.js, and Node.js) for the frontend and backend, with **MySQL** used as the database for storing and managing application data.
